## 新增需求

### 需求:JSX 技能名称正确渲染
技能名称在 UI 中必须不带前缀 `$` 符号地正确显示。

#### 场景:技能名称显示
- **当** 用户查看 ContextsPage 或 SkillsPage 中的技能列表
- **那么** 技能名称必须显示为原始名称（如 `my-skill`），而不是 `$my-skill`

### 需求:代码库无死导入
所有 TypeScript 文件中禁止存在未使用的导入语句。

#### 场景:编译无警告
- **当** 运行 TypeScript 编译器
- **那么** 不得出现"已导入但从未使用"的相关警告

### 需求:方法签名与实现一致
Repository 方法的参数必须在方法体中实际使用，或从签名中移除。

#### 场景:findByBotId 调用
- **当** 调用 `findByBotId()` 或 `findEnabledByBotId()`
- **那么** 方法签名不得包含未使用的 `botId` 参数

### 需求:前端 API 模块无未使用方法
`api/index.ts` 中定义的所有 API 方法必须在至少一个页面组件中被调用。

#### 场景:API 方法覆盖
- **当** 检查 `api/index.ts` 中的所有导出方法
- **那么** 每个方法必须在至少一个页面组件中有调用点
