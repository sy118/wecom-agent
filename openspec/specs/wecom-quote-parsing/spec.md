# WeCom Quote Parsing

## 目的

定义企业微信引用消息 `body.quote` 的解析规则，确保模型能够同时感知引用内容和当前消息。

## 需求

### 需求:WeComAdapter 必须解析引用消息
WeComAdapter 在解析企业微信消息时必须读取 `body.quote` 字段，并将被引用消息内容与当前消息一起传递给 LLM，使模型能够感知用户回复的上下文。

#### 场景:文本消息包含文本引用
- **当** 用户回复一条文本消息，企业微信回调中包含 `body.quote` 文本内容
- **那么** 系统必须将引用内容拼接到当前用户消息之前，并用明确标记区分引用内容与当前消息

#### 场景:文本消息包含图片引用
- **当** 用户回复一条图片消息，企业微信回调中包含 `body.quote` 图片信息
- **那么** 系统必须在 visionEnabled 为 true 时将引用图片作为多模态内容传递给 LLM
- **并且** 在 visionEnabled 为 false 时降级为 `[引用图片]` 文本占位

#### 场景:引用字段为空或格式未知
- **当** 企业微信回调不包含 `body.quote`，或 quote 类型无法识别
- **那么** 系统必须保持现有消息解析行为，不得阻断消息处理

#### 场景:当前消息与引用消息同时存在
- **当** 用户发送回复内容且包含引用消息
- **那么** 系统必须同时保留当前消息内容和引用内容，禁止用引用内容覆盖当前消息
