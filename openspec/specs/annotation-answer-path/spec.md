# annotation-answer-path 规范

## 目的
定义人工审核标注答案的管理、命中和来源追踪能力，使高置信问题可以优先使用已确认答案并保留反馈/草稿来源关系。
## 需求
### 需求: 标注答案管理
系统必须支持管理员维护人工审核的标注答案。

#### 场景: 创建标注答案
- **当** 管理员从反馈、草稿或手动入口创建标注答案
- **那么** 系统必须保存问题、答案、适用 namespace、适用 Context 范围、来源引用和启用状态

#### 场景: 禁用标注答案
- **当** 管理员禁用某条标注答案
- **那么** 系统必须停止在 Bot 回复路径中命中该答案
- **并且** 保留历史命中统计和来源信息

### 需求: 标注答案命中
系统必须在适用范围内优先检查已启用的标注答案。

#### 场景: 问题命中标注答案
- **当** 用户问题命中当前 Context 和 namespace 下启用的标注答案
- **那么** Bot 必须使用该标注答案直接回复或作为高优先级上下文生成回复
- **并且** 系统必须记录命中日志

#### 场景: 问题未命中标注答案
- **当** 用户问题未命中任何启用标注答案
- **那么** Bot 必须继续执行普通 Agent 回复流程

### 需求: 标注答案来源追踪
系统必须保留标注答案与反馈、草稿或人工创建来源之间的关系。

#### 场景: 从正反馈创建标注答案
- **当** 管理员从准确反馈创建标注答案
- **那么** 系统必须关联原始反馈事件和回复追踪记录

#### 场景: 从负反馈修复结果创建标注答案
- **当** 管理员从已处理负反馈创建标注答案
- **那么** 系统必须关联反馈处理项和最终确认答案
