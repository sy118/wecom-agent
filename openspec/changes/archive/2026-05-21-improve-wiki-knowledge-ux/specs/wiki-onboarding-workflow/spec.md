## 新增需求

### 需求: 可恢复配置清单
系统必须将首次使用向导扩展为可持续展示和恢复的配置清单。

#### 场景: 基础配置未完成
- **当** Wiki 基础配置缺少 namespace、wiki-mcp、MCP Server、Context 绑定或检索测试
- **那么** 页面必须展示配置清单
- **并且** 每个未完成步骤必须提供继续配置的入口

#### 场景: 基础配置已完成
- **当** Wiki 基础配置全部完成
- **那么** 页面必须继续展示清单的完成状态或收起摘要
- **并且** 管理员必须能够重新打开清单查看链路状态

### 需求: 向导步骤与工作区联动
系统必须让向导步骤和 Wiki 工作区中的配置、文档、测试检索操作保持一致。

#### 场景: 从清单进入配置动作
- **当** 管理员点击配置清单中的创建 namespace、注册 wiki-mcp、绑定 Context 或测试检索
- **那么** 页面必须打开对应 Modal、工作区或跳转入口
- **并且** 完成动作后必须刷新配置清单状态

#### 场景: 配置动作需要重启 Bot
- **当** 管理员完成会影响 Bot 工具加载的配置动作
- **那么** 页面必须提示关联 Bot 需要重启
- **并且** 必须提供跳转到 Bot 管理或执行可用重启操作的入口
