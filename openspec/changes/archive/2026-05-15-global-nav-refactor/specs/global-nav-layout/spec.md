## 新增需求

### 需求:侧边栏包含全局功能导航项
左侧边栏必须包含以下顶级导航项：机器人管理、MCP 服务器、Skills、定时任务，以及底部分区的会话监控。会话监控必须与上方功能区用视觉分隔线区分。

#### 场景:用户看到完整的侧边栏导航
- **当** 用户登录后进入任意页面
- **那么** 左侧边栏必须显示：机器人管理、MCP 服务器、Skills、定时任务（上方区域），以及分隔线后的会话监控（下方区域）

#### 场景:点击 MCP 服务器导航项
- **当** 用户点击侧边栏中的"MCP 服务器"
- **那么** 页面必须跳转到 `/mcp-servers`，且该菜单项高亮选中

#### 场景:点击 Skills 导航项
- **当** 用户点击侧边栏中的"Skills"
- **那么** 页面必须跳转到 `/skills`，且该菜单项高亮选中

#### 场景:点击定时任务导航项
- **当** 用户点击侧边栏中的"定时任务"
- **那么** 页面必须跳转到 `/scheduled-tasks`，且该菜单项高亮选中

### 需求:当前路由对应的菜单项高亮
侧边栏必须根据当前 URL 路径自动高亮对应的菜单项。

#### 场景:访问 MCP 服务器页面时菜单高亮
- **当** 当前路由为 `/mcp-servers`
- **那么** 侧边栏中"MCP 服务器"菜单项必须处于选中高亮状态

#### 场景:访问 Skills 页面时菜单高亮
- **当** 当前路由为 `/skills`
- **那么** 侧边栏中"Skills"菜单项必须处于选中高亮状态

#### 场景:访问定时任务页面时菜单高亮
- **当** 当前路由为 `/scheduled-tasks`
- **那么** 侧边栏中"定时任务"菜单项必须处于选中高亮状态
