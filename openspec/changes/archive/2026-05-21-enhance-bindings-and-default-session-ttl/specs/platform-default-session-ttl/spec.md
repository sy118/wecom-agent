## 新增需求

### 需求:平台默认会话 TTL 配置
系统必须提供平台级默认会话 TTL 配置，用于决定新建上下文在未显式指定会话 TTL 时的默认 `sessionTtlMin`。

#### 场景:新建上下文使用平台默认 TTL
- **当** 管理员创建上下文且未显式指定 `sessionTtlMin`
- **那么** 系统必须使用平台默认会话 TTL 作为该上下文的 `sessionTtlMin`

#### 场景:显式 TTL 优先于平台默认值
- **当** 管理员创建上下文并显式指定 `sessionTtlMin`
- **那么** 系统必须使用请求中的 `sessionTtlMin`，禁止用平台默认会话 TTL 覆盖该值

#### 场景:修改平台默认 TTL 不覆盖已有上下文
- **当** 管理员修改平台默认会话 TTL
- **那么** 系统禁止修改已有上下文的 `sessionTtlMin`

#### 场景:平台默认 TTL 校验
- **当** 管理员设置平台默认会话 TTL
- **那么** 系统必须校验该值为允许范围内的正整数分钟数
