## 新增需求

### 需求:管理员身份认证
系统必须对管理控制台的所有 API 请求进行 JWT 认证，防止未授权访问。

#### 场景:登录获取 Token
- **当** 管理员 POST /api/auth/login 提交正确的 ADMIN_PASSWORD
- **那么** 系统返回有效期 24 小时的 JWT token

#### 场景:错误密码拒绝登录
- **当** 管理员提交错误的密码
- **那么** 系统返回 401，不返回 token

#### 场景:未携带 Token 的请求被拒绝
- **当** 请求未携带 Authorization: Bearer <token> 头
- **那么** 系统返回 401，拒绝处理

#### 场景:Token 过期后需重新登录
- **当** 请求携带已过期的 JWT token
- **那么** 系统返回 401，前端跳转到登录页

### 需求:机器人管理界面
管理控制台必须提供机器人的完整 CRUD 操作界面和实时状态显示。

#### 场景:机器人列表展示
- **当** 管理员访问机器人管理页
- **那么** 界面必须展示所有机器人的名称、状态（运行中/已停止/错误）、今日消息数

#### 场景:实时状态更新
- **当** 机器人状态发生变化（启动/停止/错误）
- **那么** 管理台必须通过 SSE 连接实时更新状态显示，无需手动刷新

#### 场景:启动停止操作
- **当** 管理员点击启动或停止按钮
- **那么** 界面必须显示操作进行中状态，操作完成后更新显示结果

### 需求:上下文配置界面
管理控制台必须提供上下文的创建和编辑界面，包含系统提示词编辑器。

#### 场景:系统提示词编辑
- **当** 管理员编辑上下文的系统提示词
- **那么** 界面必须提供多行文本编辑器，支持输入 Markdown 格式的提示词

#### 场景:可查项目多选
- **当** 管理员配置上下文的 allowed_projects
- **那么** 界面必须提供多选组件，允许从预定义项目列表中勾选（至少一个必选）

#### 场景:设置默认上下文
- **当** 管理员将某上下文设为默认
- **那么** 界面必须清晰标识当前默认上下文，同一机器人下只能有一个默认

### 需求:绑定管理界面
管理控制台必须提供 chatKey 与上下文绑定关系的管理界面。

#### 场景:创建绑定
- **当** 管理员填写 chatKey（群ID或用户ID）、显示名称，并选择目标上下文
- **那么** 系统创建绑定关系，界面刷新显示新绑定

#### 场景:绑定列表展示
- **当** 管理员查看绑定管理页
- **那么** 界面必须展示所有绑定关系：显示名称、chatKey、绑定的上下文名称

### 需求:会话监控界面
管理控制台必须提供当前活跃会话的查看和管理功能。

#### 场景:活跃会话列表
- **当** 管理员访问会话监控页
- **那么** 界面必须展示所有活跃会话：chatKey、绑定上下文名、消息数、最后活跃时间、剩余 TTL

#### 场景:查看对话历史
- **当** 管理员点击某个会话
- **那么** 界面必须展示该会话的完整对话历史（HumanMessage 和 AIMessage 交替显示）

#### 场景:手动清除会话
- **当** 管理员点击清除某个会话
- **那么** 系统立即删除该会话，界面从列表中移除该条目
