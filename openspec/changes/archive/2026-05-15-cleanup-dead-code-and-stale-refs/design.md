## 上下文

项目经历多次迭代后，MCP Server 和 Skill 从 bot 级别资源升级为全局资源，但相关方法签名未同步更新。同时积累了死导入、未使用的前端 API 方法，以及一个 JSX 渲染 bug。

## 目标 / 非目标

**目标：**
- 修复 JSX 中 `${}` 语法误用导致的渲染 bug
- 删除所有死导入（不影响运行时行为）
- 清理死参数（方法签名与实现对齐）
- 删除前端未使用的 API 方法定义

**非目标：**
- 不改变任何业务逻辑或 API 行为
- 不重构架构
- 不添加新功能

## 决策

**JSX bug 修复**：`${skill.name}` 在 JSX 字符串中是字面量，不是模板插值。修复方式是直接使用 `{skill.name}` 或将字符串改为模板字符串表达式。

**死参数清理**：`findByBotId(botId)` 等方法的 `botId` 参数在实现中从未使用，直接从方法签名中移除。调用方也需同步更新（传参改为无参）。

**死导入删除**：直接删除，TypeScript 编译器会验证无副作用。

**未使用 API 方法删除**：`sessionsApi.get`、`skillsApi.get`、`wikiApi.updateNamespace`、`wikiApi.getFile` 在所有页面组件中均无调用，直接删除。

## 风险 / 权衡

- [死参数清理] 调用方需同步修改 → 通过全局搜索确认所有调用点
- [API 方法删除] 若有未扫描到的调用点会导致运行时错误 → 已通过全代码库扫描确认无调用
