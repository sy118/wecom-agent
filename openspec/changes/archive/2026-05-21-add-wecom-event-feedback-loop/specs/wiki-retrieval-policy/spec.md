## 新增需求

### 需求: 检索日志关联回复追踪
系统必须支持将 Wiki 检索日志关联到具体机器人回复。

#### 场景: 记录自动搜索关联
- **当** Bot 为某次用户问题执行 `autoSearch`
- **那么** 系统必须记录检索日志
- **并且** 检索日志必须包含当前回复追踪记录 ID

#### 场景: 记录固定页面读取关联
- **当** Bot 为某次用户问题执行 `fixedPage`
- **那么** 系统必须记录读取日志
- **并且** 读取日志必须包含当前回复追踪记录 ID

#### 场景: 反馈复盘查询检索证据
- **当** 管理员查看某条反馈的关联回复
- **那么** 系统必须能够查询该回复关联的 Wiki 检索日志
- **并且** 展示 query、策略、命中文档、命中数量、耗时和错误
